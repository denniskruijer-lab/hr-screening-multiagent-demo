# data_local/

This folder holds **real, non-fictional** input data: an actual CV and an actual
vacancy, used for one live demo run rather than for the automated test suite.

It is deliberately excluded from git (see the root `.gitignore`). The rest of
this project only ever commits fictional sample data (see `data/`), so nothing
in here should end up in the repository's history — this file is the only
tracked file in this directory, kept as a placeholder explaining why.
